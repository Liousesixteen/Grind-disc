# 版本存档库

**用途**：保存 `熔炼系统.md` 每一版的完整快照，供日后**对照**——看规则是怎么演化的、某条判断以前是怎么写的、某次改动是否真的更好。

**规则（用户 2026-10-18 定，已写入 `熔炼规则.md` 四 编号与引用规范 第 5 条）**：

1. **每次发布新版都要存档**——版本号一变就存，不等下次改动前才备份。
2. **命名**：`<文件名>_v<版本号>_<发布日期>.md`，例：`熔炼系统_v1.14_2026-10-18.md`。
3. **存档只读**——归档后不再修改，发现错误在新版里改，不改旧档。
4. **旧版永不删除**——包括「觉得改坏了」的版本。改坏的版本本身就是证据，它记录了哪条路走不通。
5. **正文只保留现役版**：`熔炼系统.md` 永远是当前版本，旧版只在这里。

**与 `.workbuddy/backups/` 的分工**（两者不重复）：

| 目录 | 作用 | 时机 |
|---|---|---|
| `versions/` | **公开的版本快照**，用于对照阅读 | 每次**发布**存档 |
| `.workbuddy/backups/` | **改动前的工作备份**，用于误操作回滚 | 每次**动手改之前** |

`versions/` 是给"看"的，`.workbuddy/backups/` 是给"救"的。
