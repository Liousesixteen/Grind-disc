# A股分类体系全景：行业 / 概念 / 题材 / 板块 / 地域 / 风格

> 建立日期：2026-10-17 ｜ 数据基准：全A 5923 只（数据日 2026-10-16）
> 目的：回答「A股这些细分是按什么分的、一共多少、具体有哪些」，并说明**本项目的股池为什么必须用题材口径**。
> 口径定义见 `熔炼系统.md` 3.8 板块主口径＝题材；本文件只做**分类体系的说明与清单**，不定交易规则。

---

## 〇、一句话结论

**行业是有国家/机构标准的「层级树」：稳定、互斥、一只票只有一个归属。
概念/题材是没有统一标准的「扁平网络」：动态、可重叠、一只票可同时属于几十个。**

这两者的差别，决定了 233「先板块后个股」里的「板块」**只能是题材**——因为资金是按题材炒的，不是按行业炒的。

## 一、六类标签总览

| 维度 | 谁定的 | 结构 | 稳定性 | 是否互斥 | 用途 |
|---|---|---|---|---|---|
| **① 行业** | 机构标准（申万 / 中信 / 证监会 / 国证） | **层级树**（一级→二级→三级） | 高，数年一调 | **是**（一票一行业） | 基本面、估值、资金配置 |
| **② 概念 / 题材** | **各家数据商自建，无统一标准** | **扁平网络**（无层级、可重叠） | 低，随热点增删 | **否**（一票数十题材） | **短线资金炒作的真实单位** |
| **③ 地域** | 按注册地 / 办公地 | 扁平 | 高 | 是 | 区域政策（西部大开发、深圳特区等是另一回事） |
| **④ 风格 / 规模 / 估值** | 按量化指标客观计算 | 扁平 | 中（随行情变） | 否 | 因子暴露、机构持仓 |
| **⑤ 指数成分 / 通道** | 指数公司编制 | 扁平 | 中（定期调整） | 否 | 被动资金流向 |
| **⑥ 交易状态 / 事件** | 按当日交易行为自动打标 | 扁平 | **每日变** | 否 | **是「结果」不是「原因」** |

> 关键：**①②③ 是「属性标签」（相对稳定），⑥ 是「状态标签」（每天变）**。
> 把⑥当板块用，会形成「因为涨停所以涨停」的同义反复——这正是 `熔炼系统.md` 3.8 板块主口径＝题材 要求排除它的原因。

### 层级示例（军工在行业口径下是怎么被切碎的）

```
国防军工（一级）
  ├─ 航天装备Ⅱ
  ├─ 航空装备Ⅱ      ← 10-16 均涨 5.98%、涨停 10 家
  ├─ 地面兵装Ⅱ      ← 10-16 均涨 5.97%
  ├─ 航海装备Ⅱ      ← 10-16 均涨 4.72%
  └─ 军工电子Ⅱ      ← 10-16 均涨 2.87%
```

**这就是 2026-10-16 那次漏掉军工的 mechanical 原因**：同一波资金在行业口径下被切成 5 块，单块都不够显眼，而「低空经济」这种跨行业题材在行业树里**根本不存在这个节点**。

### 为什么数量差这么多

概念/题材**没有国家标准**，是各家数据商自己维护的产品。维护方式大致两类：

1. **静态收录**：人工维护一份题材名单（政策类、产业类、地域类），定期更新 → 数量少、稳定但滞后
2. **动态挖掘**：用算法（文本、资金联动、龙头带动）实时识别市场正在炒的题材 → 数量多、快但噪音大、主观

**选择哪家的题材库，本身就决定了你能看到什么。** 这正是 `熔炼系统.md` 3.8 板块主口径＝题材 粒度判据第一条要求「**题材必须有可观测的资金读数**」的原因——题材库是主观的，资金读数才是客观的；没有读数的题材只是个名字。

### ⑥ 交易状态 / 事件（**必须排除**）

昨日涨停、昨日首板、昨日连板、昨日炸板、昨日触板、昨日高振幅、昨日高换手、昨日打二板以上表现、新股与次新股、次新股、ST股、破发股、近期新高、百日新高、股权激励、高送转、转债标的、2026中报预增 / 2026三季报首亏 …

> 本项目已在 `scripts/pool_config.json` 的 `granularity.exclude_words` / `exclude_regex` 中排除（含 `^昨日.*` 正则，一次性覆盖所有「昨日*」）。

## 五、对本项目的意义（为什么股池必须用题材口径）

1. **资金是按题材炒的，不是按行业炒的。** 低空经济横跨航空装备 / 汽车零部件 / 通信设备 / 军工电子，行业树里**没有这个节点**，用行业口径永远看不到它。
2. **题材是重叠网络。** 一只票同时属于多个题材是正常的（233 的龙头本就是多题材共振），所以股池**不做唯一归属**，允许重复计入。
3. **题材库是主观的，资金读数是客观的。** 所以题材必须能在板块榜上匹配到（当日/5日/20日涨幅、主力净流入、涨股比），否则只是一个名字。实测 717 个题材里只有 **245** 个满足。
4. **题材宽度差异极大。** 军工 575 只 vs 印巴冲突概念 11 只，同样对待必然出错 → 粒度三判据（可观测 / 宽度 15—350 / 连续性 ≥2 日）。
5. **题材标签很宽松（沾边即打标）。** 所以「有题材 + 有涨停基因」≠「是这个题材的龙头」→ 必须在**题材内部相对比较**（题材内涨幅 / 涨停先后 / 成交额），取「题材内领涨 × 池内核心」的交集。
