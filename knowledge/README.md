# 知识库

本目录保存可持续更新的行业研究与交易方法论。任何催化剂、估值、产能、订单、政策、公司事件和资金数据都必须记录来源及日期；任何经验规律必须标注 A/B/C/D 证据等级。

## 方法论

- `methodology/boge-deep-study.md`：波哥 2025-08 至 2026-08 逐日复盘的批判性吸收、月度摘要与关键案例。
- `methodology/boge-archive-index.md`：351 个发布时间戳的逐篇覆盖台账、指纹和重复标记。
- `methodology/boge-hypothesis-register.md`：从原文抽取、尚未证明的 C 级可回测假设。
- `methodology/style-and-trend-notes.md`：交易风格、相对强弱和趋势识别笔记。

方法论材料不能直接覆盖 `熔炼系统.md` 的生存纪律（A 级纪律自 2026-10-18 起全部收在 `熔炼系统.md`；`TRADING_OS_V4.md` 已降为只读母本）。来源中的收益展示、绝对化判断和个人叙事不构成证据；只有经过定义、复核和回测的规则才能升级。

## 行业研究

所有行业均在覆盖范围内，统一入口为 `sector-research-standard.md`。该文件定义 L0—L4 成熟度、十二层研究闭环和各行业专属最小指标集；新行业研究按任务即时建立文件，不设置永久排除项，也不因文件尚未建立而编造结论。

当前已沉淀或计划优先维护的专题文件：

- `semiconductor.md`
- `commercial-aerospace.md`
- `robotics-humanoid.md`
- `huawei-ascend.md`

这份专题清单只代表当前沉淀进度，不代表能力范围。未完成数据验收时明确标注成熟度与缺失项，完成后持续更新。

建议每份行业文件采用以下结构：

1. 一句话产业结论。
2. 超长、长、中、短四层周期定位。
3. 产业链地图、利润集中环节与核心瓶颈。
4. 供需数据及二阶导。
5. 核心公司与横向估值。
6. 已定价与未定价预期。
7. 催化剂日历。
8. 证伪条件与主要风险。
9. 来源、数据日期与待验证问题。
