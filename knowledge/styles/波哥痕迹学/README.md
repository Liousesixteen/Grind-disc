## 使用纪律（重要）

1. **按本体系执行时必须显式声明**——「本分析按波哥痕迹学体系执行」，并**单独分账**，不与其他体系仓位混用（见 `熔炼系统.md` 十一 体系选择协议）。
2. **仅 A0 生存底线兜底**：止损纪律、不加杠杆摊平、行为门禁仍适用；本体系的仓位与点位**不得覆盖**主框架硬顶（20% 现金 / 隔夜 ≤60% / 首仓 1/3）。
3. **本体系的适用对象是指数 / 股指期货 / 宽基 ETF**。原文几乎不谈个股；把它的左侧点位法直接用于个股，等于用可分散工具的方法去赌不可分散的风险（主框架层4 明确禁止）。
4. **D 级内容不得使用**： 「国家队精准控盘每个点位」「大盘涨跌与政策消息无关」两条为不可证伪叙事；「只看价不看量」与 A1 冲突，不采纳。详见知识库第九章。
5. **点位会过期**：原文中所有具体点位（3741.11 / 4258.86 等）都是**当时**的微浪型划分点，不得当作现在有效的价位。
