# 风轻云淡 风格体系（独立隔离区）

> 目录：`knowledge/styles/风轻云淡/`
> 命名说明：原始材料中写作「风清云谈」，本项目按用户要求统一命名为「**风轻云淡**」。两者指向同一套体系。

本目录是一套**独立的交易风格体系**，与项目其余部分**相互隔离、互不混用**。

隔离对象：

- `熔炼系统.md`（主交易框架与生存纪律；`TRADING_OS_V4.md` 为只读母本）
- `knowledge/methodology/`（波哥复盘体系等既有方法论）
- `knowledge/sector-research-standard.md` 及各行业研究
- `portfolio/`、`journal/`、`watchlists/`

## 一、隔离规则

1. 本目录内容只作为「一套可选交易风格」的素材与规则集**单独存放**，不自动并入主交易系统的决策回路。
2. 引用本目录规则做分析时，必须显式声明「按风轻云淡体系」，并在输出中与主体系分账，不得把两套参数混用在同一笔交易上。
3. 本目录的仓位上限、止损档位、时间窗口等参数均来自第三方材料整理，**未经回测验证，不得覆盖 `熔炼系统.md` 的生存纪律**（永留 20% 现金、收盘隔夜仓位通常不超 60%、首次只建计划仓位 1/3 等）。
4. 体系内部存在两套不同的仓位哲学：「首板战法」双 30% 硬顶、「龙头追踪」弹性上限 + 5% 分仓隔离法。二者只在各自场景自洽，禁止跨场景挪用理由。
5. **自救体系（v3.3 新增，见 3.8）与主框架「禁止向下摊平」方向相反**（本体系允许「暴跌直接加仓」摊低成本自救）——按本体系执行时必须显式声明所属体系并单独分账，**不得混入主框架仓位**；同理「目标 8%」「很少一次买满 / 破位留底仓看戏」均为本体系特有口径，不等于主框架纪律。
