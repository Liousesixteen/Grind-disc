> 体系定位：**短线 / 板块轮动 / 半路追涨停**的一套**流程筛选法**。

## 〇、体系总览

三个数字：

| 数字    | 内容                            |
| ----- | ----------------------------- |
| **2** | 2 个核心原则：先板块后个股；不预测只跟随         |
| **3** | 3 个筛选标准：股性、辨识度、量价（盘前建股池）      |
| **3** | 3 个确认信号：板块确认、龙头确认、买点确认（盘中定出手） |

**一句话流程**：盘前选好，盘中等钱，方向确认，跟随最强。

**体系要解决的核心问题**（原文）：  
不是「怎么猜到下一只涨停」，而是**层层缩小范围**——  
先把几千只股票缩小到一个**股池**，再把一个股池缩小到**当天最强板块**，最后把一个板块缩小到**最强核心**。

**体系性格**：  
不预测涨停，只寻找共振；不追求买在最低，只追求买在**确定性出现之后**。

### 0.1 适用场景与不适用场景

| 适用              | 不适用                                   |
| --------------- | ------------------------------------- |
| 板块轮动行情、主线有赚钱效应时 | 无主线的混沌市、普跌市（原文未讨论，体系亦无应对规则，**视为不适用**） |
| 当日资金已明确进攻某方向    | 资金方向未明、板块确认不成立                        |
| 短线 / 超短，日内到数日   | 长线、基本面投资（体系不含基本面维度）                   |

> ⚠️ 原文**通篇未涉及仓位上限、止损、止盈、被套处置、大盘环境过滤**。这是本体系的**结构性缺口**，按本体系执行时必须由主框架 A0 生存纪律兜底（见第五章）。

## 一、2 个核心原则

### 1.1 先板块，后个股

**原则表述**：短线不要脱离板块单独看一只股票。个股能持续走强，背后通常需要**板块 + 题材 + 资金**共同推动。

**顺序永远是先判断资金进攻哪个方向，再从这个方向里找核心。**

四种状态下的板块处理：

| 市场状态           | 动作                |
| -------------- | ----------------- |
| 主线强势           | 做主线               |
| 主线产生赚钱效应以后     | 关注资金向其他题材**溢出**   |
| 主线调整           | 观察资金是否**切换到新的题材** |
| 一个轮动题材不断获得资金强化 | 可能逐渐从**支线走成新的主线** |

**浓缩**：板块决定方向，个股决定弹性。

> 📌 **体系内重要概念**：支线不是永远的支线。判断依据是「是否**不断获得资金强化**」——这是本体系对板块演化的唯一判据（定性，无量化阈值）。

### 1.2 不预测，只跟随

**原则表述**：不需要提前猜今天谁一定涨停，市场每天都会自己给出答案。

**做法**：提前准备好股池 → 等待资金选择方向 → 方向出现以后，跟随最强的资金。

**成本观（原文核心取舍）**：

> 宁愿**买贵一点**换确定性，也不为了买得便宜而**提前赌方向**。

## 二、3 个筛选标准（盘前建「核心股池」）

**为什么要提前建池**：不是等股票突然拉升以后再去几千只股票里找，而是**提前把最可能成为资金攻击对象的股票筛出来**。

### 2.1 股性第一 —— 看「涨停基因」

- 看有没有**涨停基因**：历史涨停次数多、股性活跃、资金反复参与过。
- 底层逻辑：**市场记忆**——过去资金喜欢攻击谁，下一次同类型行情出现时，它依然值得重点观察。

### 2.2 辨识度第二 —— 看「市场共识」

- 看**市场辨识度**：前期龙头、人气股、容量核心、反复活跃的强势股，都属于市场容易形成**共识**的标的。
- 反面：**短线最怕买一个没人认识、没人关注、没有资金记忆的股票**。
- **同一板块内：优先核心，不做杂毛。**

### 2.3 量价第三 —— 看「红肥绿瘦」

一种很直观的状态：

| 维度  | 要求                |
| --- | ----------------- |
| 上涨时 | 阳线大、攻击性强          |
| 调整时 | 阴线小、承接强           |
| 成交量 | 活跃，有放量、有换手、有足够流动性 |

**简单概括**：涨得猛，跌得慢；阳线大，阴线小；有量，有人，有资金。

### 2.4 股池纪律

- 符合三条标准的股票，**提前进入股池等待**（盘前完成）。
- 股池是**准备**，不是买入清单——是否出手由第三章的三个确认决定。

## 三、3 个确认信号（盘中决定是否出手）

**股池只是准备。真正决定是否出手的，是当天盘面给出的三个确认。**

### 3.1 板块确认 —— 今天的钱到底去了哪里

**四个观测时点（本体系最具特色的可执行规则）**：

| 时点        | 观察什么                        |
| --------- | --------------------------- |
| **9:25**  | 集合竞价——观察市场**当天最初的资金选择**     |
| **10:30** | 开盘第一轮博弈结束后，哪些方向**真正经受住了分歧** |
| **13:00** | 午后资金有没有**回流**，或者出现**新的方向**  |
| **14:30** | 尾盘资金选择，以及市场对**第二天**的预期      |

**关键纪律**：

> 不要因为自己昨天看好一个板块，今天就一定要做它。**昨天的判断只是预案，今天的资金才是答案。**

### 3.2 龙头确认 —— 找板块里最主动的股票

重点观察六项：

1. **辨识度**
2. **涨停基因**
3. **5 日线突破**
4. **成交量**
5. **涨速**
6. **板块带动性**

**关键区分（原文强调）**：

> **涨得最快，不一定就是龙头。**

真正值得做的，是**本身具有辨识度** + **主动突破关键位置** + **能得到板块资金响应**的核心标的。

**目标**：最强板块里的最强核心。

### 3.3 买点确认 —— 半路

**三种交易方式的取舍**：

| 方式     | 本体系态度   | 理由                   |
| ------ | ------- | -------------------- |
| 埋伏     | 不首选     | 埋伏是在**资金确认之前**下注     |
| 低吸     | 不首选     | 同上（偏左侧）              |
| **半路** | **最喜欢** | 半路是在**资金已经开始表态以后**跟随 |

**出手前要看到的共振条件**：

- 板块在涨
- 核心在动
- 量能在放
- 股价在突破

几个条件**形成共振**，再考虑跟随。

**放弃规则（本体系的 A0 级自我保护）**：

- 如果第一核心已经错过 → 就观察**第二、第三核心**。
- 如果**没有舒服的机会 → 就放弃**。
- **错过不是亏损，乱做才是。**

## 四、完整流程图

```
【盘前】
  建立核心股池
    ├─ 股性（涨停基因 / 市场记忆）
    ├─ 辨识度（前期龙头 / 人气 / 容量核心 / 活跃强势股）
    └─ 量价（红肥绿瘦 / 有量有人）
          ↓
【盘中 · 四时点扫描】
  9:25  集合竞价 → 当天最初的资金选择
  10:30 第一轮博弈后 → 谁扛住了分歧
  13:00 午后 → 资金回流 or 新方向
  14:30 尾盘 → 资金选择 + 次日预期
          ↓
  【确认 1】板块确认：今天的钱去哪了
          ↓
  【确认 2】龙头确认：最强板块里的最强核心
            （辨识度 + 主动突破 + 板块响应；涨得最快 ≠ 龙头）
          ↓
  【确认 3】买点确认：半路跟随
            （板块涨 + 核心动 + 量能放 + 股价突破，四者共振）
          ↓
  第一核心错过 → 看第二、第三核心
  没有舒服机会 → 放弃
```
