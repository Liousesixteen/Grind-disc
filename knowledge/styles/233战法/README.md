## 一、隔离规则

1. 本目录内容只作为「一套可选交易风格」的素材与规则集**单独存放**，不自动并入主交易系统的决策回路。
2. 引用本目录规则做分析时，必须显式声明「按 233 战法体系」，并在输出中与主体系分账，不得把两套参数混用在同一笔交易上。
3. 本体系的**四个盘中时点**（9:25 / 10:30 / 13:00 / 14:30）虽已被主框架吸纳为 `熔炼系统.md` 3.5 日内资金选择时钟，但**吸纳 ≠ 取代**：本目录原文口径继续原样保留，被吸纳进主框架的部分按主框架执行，未被吸纳的部分仍只在本体系内成立。
4. **本体系原文不含仓位、止损、止盈、被套处置、大盘环境过滤**——这是结构性缺口。按本体系执行时必须由主框架 **A0 生存纪律**与**第六章离场理论**兜底（永留 20% 现金、隔夜 ≤60%、首次只建计划仓位 1/3、禁止杠杆摊平）。
5. **「宁愿买贵一点换确定性」不得被用作追高接盘的理由**：本体系口径仅在**启动相**成立；处于**派发相**时该条失效，必须回到主框架防守线。
6. 本体系为短线 / 超短口径，**日内/超短档在主框架定位为高难档**；按本体系执行时仍须先过主框架层 1 环境过滤，环境系数过低则本体系不出手。

## 七、盘前股池（本体系的落地工具）

- 生成脚本：`scripts/pool_pipeline.py` v1.2（一条命令：采数 → 算指标 → 三筛选分层 → 题材/行业双维度 → 导表 → 落盘 → 记台账；参数全在 `scripts/pool_config.json`）
- 交付工作簿：`watchlists/233战法盘前股池_<数据日期>.xlsx`（Downloads 同名下另存一份）
- 结构（v1.2）：
  - **窗口A·题材强度榜（主表）** —— 按主力净流入排序的题材榜，带成分股数 / 宽度判定 / 当日·5日·20日涨幅 / 主力净流入 / 涨股比 / 连续性 / **题材内领涨** / **池内核心**
  - **窗口B·行业取用** —— 行业口径兜底与交叉验证（按当日均涨排序）
  - **窗口C·全A股池明细** —— 5923 只 × 三筛选字段 × 题材标签
  - **窗口D·老龙记忆** —— 涨停集中在 61—120 日区间、近期不活跃但市场有记忆（对应本体系「过去资金爱攻击谁」）
  - **口径与来源说明**
- 纪律：池层只决定**候选资格**，不决定仓位；仓位仍由主框架第五章方程决定；板块进攻但池内无标的 → 默认不追。
- **两个口径要点**（v1.2 由实战核验反例确立）；口径见 `熔炼系统.md` 3.8 板块主口径＝题材：
  1. **板块主口径是题材，不是行业**——题材跨行业（低空经济横跨航空装备 / 汽零 / 通信设备 / 军工电子），行业口径会把它切碎而丢失信号。
  2. **三筛选不能判定龙头**——它是全市场绝对阈值，只能证明「有涨停基因」；本体系的龙头六项是**题材内相对比较**，所以窗口A 的个股一律按题材内当日涨幅展示，取「题材内领涨」×「池内核心」的交集。
