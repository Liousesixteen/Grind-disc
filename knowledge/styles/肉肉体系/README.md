## 六维度速查

1. **题材逻辑**（最核心）：级别四档（国家级＞行业变革＞新技术＞消息刺激）／催化硬核度／板块容量／**预期差**
2. **个股筹码**：流通市值偏小／低位横盘优于高位／减持解禁是利空／ST 立案暴雷剔除
3. **盘口技术**：最先涨停拿席位／封板质量（炸板回封 vs 跳水）／换手三段（首板适度·连板温和·过高分歧过低锁死）／低位启动优于高位接力
4. **梯队与卡位**（重中之重）：小弟助攻龙头才稳／**谁先涨停谁封板强谁拿龙头席位**／中军不倒题材不倒
5. **情绪周期定上限**：冰点后龙头空间大／高潮末期龙头见顶
6. **辨识度**（玄学，仅辅助）：名字代码／历史股性／消息持续发酵
