## 七、完整方案（按优先级，每步可独立交付）

### P1 让库"会说话"（最优先，半天）

**主题树 + 概念共现网络**
- 用 `rel_stock_concept` + `rel_ths_member` 构建概念共现矩阵（同一只票挂两个概念 = 一条边）；
- networkx Louvain 社区发现 → 自动聚出"题材簇"；
- 输出：`theme_cluster`（簇 ID / 成员概念 / 强度 / 生命周期）+ 每日"新簇出现"告警；
- **价值**：在概念还没被市场命名时就发现它（如"固态电池+锂矿+设备"同时出现 → 新簇）。

### P2 交付物（1 小时）

**全量库 xlsx 重出**
- Sheet：坐标（19/110/346）、概念（699+1,694+248）、产品（13,854）、ETF（1,901）、资金流、龙虎榜、股东；
- 每个 Sheet 带"数据来源 + 更新时间"页脚。

### P3 补数据（各半天）

| 项 | 动作 |
|---|---|
| Tushare 概念清单 | 冷却后 1 次调用，入 `ts_concept` |
| 产品映射 44%→75% | 环节词扩表 + 产品别名 |
| 多日事实 250 天 → 5 年 | Tushare daily 回补 1,000 天 |

### P4 补硬缺口（需决策）

| 项 | 选项 |
|---|---|
| S3 供需 | ①年报 PDF 解析（33GB，2–3 天）②CNOpenData（面议，买即用） |
| ETF 分钟级 | 需更高档位（`etf_mins` 无权限） |

### P5 上线（半天）

**远程部署**：按 `docs/方案-远程部署-v1.md` 执行——2C4G 云服务器 + Caddy + systemd timer（15:10 增量、20:30 补龙虎榜）。

### P6 应用层（后续，你已说先不做）

看板接库 → 主题榜/资金榜/ETF 净申赎榜 → 多智能体工具层。
