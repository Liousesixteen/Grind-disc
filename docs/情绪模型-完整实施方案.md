# 三组情绪模型 · 完整实施方案 v1.0

> 原型：博主「小豆小瓜」情绪模型——散户 / 机构 / 自媒体 三组 × 正面/中性/负面占比，**核心读数＝看空比例随时间的变化**（例：散户 19%→13.5%、机构 2%→0%、自媒体 16%→6%，叠加「逢利空不跌」→强势）。
> 现状：**四组已全部跑通**（散户＝股吧、机构＝研报、自媒体＝资讯、微信群＝手动导出通道），报告与「与上次对比」自动生成。
> 日期：2026-10-18　·　状态：M1 已完成，M2—M5 待推进

## 0. 一页总览

```
数据层 ──→ 分类层 ──→ 聚合层 ──→ 信号层 ──→ 回测层
股吧/微信群/      词表(C级)      四组×三档     看空Δ×价格    快照×次日收益
研报/资讯/财富号   →LLM升级      %对比上次     四象限        证据C→B升级
```

铁律：**模型只产读数，不产买卖判断**。情绪读数必须与价格、量价互证后，由交易体系（熔炼系统）裁定。

## 3. 微信群专题（合规边界 + 操作规程）

**为什么只能手动**：微信没有开放读取群消息的 API；协议逆向/HOOK/云控违反微信协议，且群聊内容属个人信息，处理缺合法性基础。工具不做、也不建议做任何自动接入。

**合规做法（已建好）**：
1. 你在自己群里看到值得记录的讨论 → **合并转发给自己** → 复制粘贴；
2. 存成 `data/wechat_exports/<代码或主题>/<YYYY-MM-DD>.txt`（格式模板：`data/wechat_exports/_格式模板.txt`，支持「发言人+时间+正文」块式与一行一条两种）；
3. 运行 `.venv/bin/python scripts/wechat_ingest.py --key 300750 --date 2026-10-18`；
4. 下次跑 `sentiment_model.py` 时，微信群自动作为**第四组**并入报告（只取近 3 天内的最新导出）。

**采样规程（建议，让样本可比）**：每天固定时间（如收盘后）导一次；每次 ≥50 条；固定同一个/同几个群；记录群人数。样本是自选群，**只作对照，不单独成信号**。

## 4. 分类器升级路径（现在最薄弱的环节）

- 现状：词表规则，C 级草案。已知漏例：**「主力在出，先撤」**（负面但未命中）——不吃否定、反讽与上下文。
- 路线①（快）：扩词表 + 否定前缀规则 → 仍是 C 级，治标。
- 路线②（推荐）：**LLM 分类**。语料已全部落盘（`cache/sentiment/<key>/*.json`），两条实现方式：
  - a. 云服务免密钥 LLM（WorkBuddy 云服务自带模型调用，脚本可直接接）；
  - b. 会话内由我直接对当日语料打标（适合起步期）。
  做法：加 `--llm` 开关，LLM 结果与词表结果**双轨并存**落盘，对比一致率。
- 升级判据（A5 证伪）：LLM 与词表一致率 + 与人工抽检一致率达标后，LLM 才转正为主分类器，词表降为兜底。

## 5. 信号层设计（读数 → 可观察的结构）

1. **核心读数**：各组看空比例的 **Δ 与连续方向**（博主用法原样本地化）。
2. **情绪-价格四象限**（与当日涨跌互证）：

| | 价格强 | 价格弱 |
|---|---|---|
| **看空收敛** | 逢利空不跌（强信号候选） | 阴跌中继（谨慎） |
| **看空发散** | 情绪过热（警惕） | 退潮确认 |

3. **情绪温度分（0—100）**：多源加权合成（股吧 + 微信群 + 投票 + 人气榜），权重 C 级待回测标定。
4. 铁律：任何情绪读数不单独触发交易；必须与层1环境、层2方向、量价结构串联。

## 6. 回测与证据升级闭环

- 每次快照自动与**次日涨跌**配对入库（现在就存，攒够再用）；
- 样本 ≥60 个交易日出第一份统计：看空收敛日 vs 发散日的次日均值/胜率差；
- 统计显著 → 词表与阈值从 C 级升 B 级（登记进证据等级台账），反之降级或废弃。

## 7. 运维约定

### 股吧风控事件（2026-10-18 21:40，v1.8 处理）

- **现象**：题材层 25 只 × 2 页高频抓取后，股吧返回 2826 字节页面、title=「身份核实」，post_title 全部消失（不是改版，是风控验证页）。
- **已加防护**：①按「代码+日期」缓存（TTL 6h，当日重跑不请求）；②识别验证页立即全局停止、不重试；③页间 sleep 1.2s、单次请求上限 40；④行业/题材取样降为 12 只×1 页。
- **恢复建议**：冷却 2—4 小时后重跑；当日已缓存的票可直接复用。
- **降级源评估**：东财搜索接口 `gubaArticleWeb`（keyword=代码）可用，但为全文检索口径——返回大量跨股组合帖（提到该代码的其他股票帖子）、时间乱序，**只作补充，不作主源**。
