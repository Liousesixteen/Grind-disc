# 量化优化（二）：排序与组合约束

日期：2026-10-28（Asia/Shanghai）。本文件记录排序口径与回测组合约束的改造、验收与边界，不是收益承诺。

## 结论

1. **排序不再按“资料填得全”**：主排序键改为 `risk_adj = 20日相对收益 ÷ 20日已实现波动`，资料缺失数只做最后的兜底，不再把“字段少一个”排到前面。
2. **回测加入三道组合闸门**：单笔风险预算（默认 0.5% NAV）、相关性合并后的组暴露上限（默认 20%）、单日新开仓上限（默认 3 只）。三者都是上限，不改变“首次 1/3、现金 20%、隔夜 60%”的硬顶。
3. 全部改动通过 100 项测试（新增 11 项），旧实验冻结不变；6063 需重启后生效。

## 一、排序：从“完整度”到“风险调整后的相对强度”

**旧口径**（8 条路径相同）：

```
readiness → setup_state → failed_conditions → pool_tier → relative20 → missing_count
```

问题：`failed_conditions` 与 `missing_count` 都是“缺多少”，在状态相同时，**少缺一项的标的会排在更值得观察的标的之前**；这正是产品二次审查里指出的误导。

**新口径**：

```
readiness → setup_state → risk_adj → pool_tier → relative20 → failed_conditions → missing_count
```

- `readiness`（数据/政策）仍是硬门禁，放第一位；
- `setup_state`（技术形态）第二位，避免“形态没形成但相对强度高”被顶上来；
- `risk_adj` 为主排序：同一形态下，单位波动获得的相对收益越高越靠前；
- `pool_tier`、`relative20` 为次级；
- `failed_conditions`、`missing_count` 降为兜底，不再主导。

**计算**（`strategy_history.features` + `strategy_engine`）：

- `vol20` = 最近 20 个交易日复权日收益的样本标准差（%）；
- `relative20` = 个股 20 日收益 − 同题材研究池中位（至少 3 只有效样本）；
- `risk_adj = relative20 / vol20`；分母缺失或 ≤0 时留空（`None`），**不填 0**，排序按 `inf` 沉底。

**验收**：
- `test_catalog_ranks_include_risk_adjusted`：8 条路径的前三位都是 `readiness/setup_state/risk_adj`；
- `test_risk_adjusted_key_prefers_higher_excess_per_vol`：2.0 排在 1.0 前；
- `test_missing_risk_adjusted_sinks_without_faking_zero`：缺失为 `inf`；
- `test_universe_sorts_by_risk_adjusted_excess`：三只同题材、同状态标的按 `risk_adj` 0.30 / 0 / −0.075 排序；
- `test_vol20_is_present_and_not_faked`：不足 21 根 K 线时没有 `vol20`，不补零。

**边界**：`relative20` 仍是“本次研究池”的中位，不是全市场/行业中性；池只有 827 只时，分母偏小。下一步应改为全市场同行业中位（需把行业映射接进研究库）。

## 二、回测：三道组合闸门

`scripts/research_backtest.simulate` 新增参数（默认值）：

| 参数 | 默认 | 作用 |
|---|---|---|
| `risk_per_trade` | 0.005 | 单笔最大风险 = 0.5% NAV；手数 = 风险预算 ÷（买入价 × 止损距离） |
| `group_corr` | 0.70 | 与现有持仓 60 日收益相关性 ≥0.7 视为同一风险组 |
| `group_cap` | 0.20 | 同一风险组的总暴露 ≤20% NAV |
| `max_new_per_day` | 3 | 单日最多新开 3 只 |

**执行顺序**（每次买入）：

```
仓位预算 = min(计划仓×1/3, 剩余暴露, 现金−20%)
→ 容量（上一交易日成交量×1%）
→ 风险预算（0.5% NAV ÷ 失效距离）
→ 相关性组暴露（同组合计 ≤20%）
→ 单日新开上限
```

- 风险预算按**失效距离**折算手数，止损越远、手数越小；它不是目标仓位，只是上限。
- 相关性组用 60 日复权收益的皮尔逊相关做代理；不足 30 个共同收益样本时不合并（避免用短样本误判）。
- 默认 10% 计划仓位下，首仓 3.33%、8% 止损对应 0.27% NAV 风险，低于 0.5%，所以**默认参数不会改变原有仓位**；只有计划仓位较大或止损较近时，风险预算才生效。

**验收**（`tests/test_portfolio_constraints.py`）：
- 风险预算 0.1% vs 2%：前者手数更小，且风险不超过预算；
- 完全相关的第二只被组上限挡住，跳过原因含“相关性”；
- 负相关两只可同时开仓；
- 单日上限=1 时只开一只；
- 非法参数（0 风险、阈值=1、组上限 0、单日 0/2.5）被拒绝。

## 三、对现有实验的影响

- 旧实验的 `settings` 已冻结，新增参数用默认值补齐后重放，**历史结果不重算、不覆盖**。
- 新实验默认带三道闸门；如果某次实验的 `position_fraction` 较大（如 0.6），风险预算会显著压缩单笔仓位——这是有意的，不是 bug。
- 6063 的策略实验页不需要改表单即可使用默认值；若要暴露参数，后续再加。
