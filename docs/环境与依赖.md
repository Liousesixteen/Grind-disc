# 环境与依赖（项目约定）

> **铁律：本项目所有 Python 依赖一律装进项目本地 `.venv/`，禁止全局安装、禁止装进任何跨项目共享环境。**

## 解释器与运行方式

| 用途 | 命令 |
|---|---|
| 跑本项目任何脚本 | `.venv/bin/python scripts/<脚本>.py` |
| 装新依赖 | `.venv/bin/pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 重建环境 | `.venv` 删除后：`/Users/ccdemac/.workbuddy/binaries/python/versions/3.13.12/bin/python3 -m venv .venv` 再装 requirements |

- PyPI 官方源在本机只有 ~30KB/s，**一律用清华镜像** `-i https://pypi.tuna.tsinghua.edu.cn/simple`。
- 基础解释器用 WorkBuddy 托管的 Python 3.13.12（只是用来创建 venv，不往它装包）。

**共享环境已清空**（只剩 pip 本体），本项目脚本现在**只能**用 `.venv/bin/python` 运行：

⚠️ **避免原程序跑不通的提醒**：
1. 旧习惯 `python3 scripts/xxx.py`（系统 Python 3.9）或
   `/Users/ccdemac/.workbuddy/binaries/python/envs/default/bin/python`（已清空）**会报 ModuleNotFoundError**；
2. 其它会话/自动化若引用了旧解释器路径，需要改为 `.venv/bin/python`；
3. 临时借用：`.venv/bin/python` 后接任何脚本即可；想省事可
   `source .venv/bin/activate` 后直接用 `python`。

## 两个 sdist 例外的手工步骤

沙箱无法构建 sdist 源码包（pip 报 `EEXIST: mkdir`），纯 wheel 不受影响：

1. **jsonpath**（akshare 依赖）：单文件模块。下载 sdist 后把 `jsonpath.py` 直接拷进
   `.venv/lib/python3.13/site-packages/jsonpath.py`。
2. **py-mini-racer**（akshare 依赖，仅个别巨潮 cninfo 函数用到）：
   site-packages 里放垫片 `py_mini_racer.py`（已内置），调用相关函数时才报
   `NotImplementedError`，其余功能不受影响。
