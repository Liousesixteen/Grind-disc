# 策略研究框架与验证协议（2026-10-27）

本轮落地在 6063，保留 6060 原版的深色、密集表格、左侧导航、链与环节分组。原来的 40/25/20/15 加权候选不再作为 6063 的研究输出。当前版本供审核，未创建 PR。

## 一、裁定口径与边界

默认裁定来自《熔炼系统》v1.24；《熔炼规则》负责来源、证据、版本与进化程序。233、风轻云淡 v3.3、波哥可执行版 v3.3、肉肉原体系及 10月27日题材图谱分别映射为观察路径，不把彼此不同的周期和买卖理由合成一个总分。v4.5 只读母本不参与冲突裁定。作业节奏、执行手册、数据源政策和行业研究标准作为作业与数据约束。

源文件及 SHA256 保存在 `config/strategy_catalog.json`。源文件修改会使版本一致性门槛失败，必须复核映射；不会自动沿用此前的核验。不会改写体系原文、把 AI 产业图谱当成证券题材标签或采纳字辈玄学。

用户持仓文件为空，工具只做观察和研究预案，不假设个人持仓、现金或盈亏，不给出账户可用仓位，不连接账户、不下单。现金至少20%、隔夜通常不超过60%、首次计划仓位1/3、风格分账等纪律仍须执行。半导体默认ETF；程序不推断个股例外授权。

## 二、由分数排序改为独立门槛

每条路径依次核验：行为门禁、周期/环境、流动性与资金去向、方向与标的、预期与风险、执行预案与复盘。每个条件保留字段、比较方法、阈值、来源、证据级别、实测值、输入时点及解释。

- 通过：有效输入满足该条规则。
- 未通过：有效输入不满足，不得以其他因子的表现抵消。
- 缺证据：缺数据、未到确认阶段或没有有效人工依据；不补成零分、通过或买入。
- 路径状态：有未通过项为“条件不符”；没有未通过但缺证据为“证据待补”；全部满足仍标“条件齐备·待验证”。

列表顺序为：核验状态 → 缺失条件数 → 核心/备选/池外 → 同题材研究池20日收益中位差 → 代码。它是浏览次序，既不表示概率，也不表示不同策略之间的优劣。没有综合分、预测胜率或收益承诺。源版本一致性也参与门槛。

人工证据按“证券＋研究路径＋条件”存储，要求来源理由、核验时刻和有效期。只有宏观/环境允许在同一路径内设全局依据。短线核验不自动放行波段或长线，人工输入不能覆盖行情、量价等自动字段。

## 四、数据与时间契约

本轮以Tushare daily＋adj_factor补采2026-04-28至2026-10-26的120个交易日，120个分区成功、663,376条日线。保存原始gzip与规范化股票日线，成交量统一股、金额统一元，价格使用截至计算时点的复权基准。独立库为 `cache/product/history.sqlite`，不使用混合单位旧快照填指标，不覆盖主库。

预盘指标只读上一交易日及以前的完整日线；缺失、停牌导致窗口不连续时缩短有效窗口，不能跨过缺失行假装连续。当日昨收和历史收盘出现明显基准冲突时，相关跨日突破/技术确认保持待核验。

6063独立抓取底层行情，来源为明确标注的腾讯备用报价；Tushare是日频研究主源。没有把已充值等同于拥有全部实时接口权限，也没有自动购买权限。ETF市场前缀已修正；ETF历史本轮尚未补采，图表会显示缺失，不能借用股票日线。

研究盘前池单独选择今天以前已完成的正式池，不把今天收盘刚产出的池塞回今天的研究信号。后台股池任务中尚未写完焦点索引的目录不能用于启动。盘前池必须与权威日历的上一交易日一致才能通过入池门槛，过旧不能悄悄沿用。

所有行情显示来源时刻；连续交易窗口采用90秒时效阈值，非连续交易标回看。抓取时刻、源时刻、研究生成时刻、历史截止日分开显示。行情缺失不删除该研究行。既有A股主快照盘后自动降频，研究层每15秒检查状态和预案，不意味着收盘后每15秒有新成交。

## 五、产品交互修复

1. 盘口点击行只展开该股研究入口；相关共享题材池单独打开，明确“同主归属，不证明父股带动”。共享池按池层、代码排序，显示范围、数量与逐只源时刻。
2. 股票名称打开详情，“加入自选”单独操作；重复添加不重复记观察。
3. 详情含真实已完成日线、规则逐项证据与失效条件、原始观察记录。行情或历史缺失时明确留空。
4. 自选主档跨日保存，历史观察记录不覆盖。保留加入时池层与当前池层、风格、场景、备注；支持搜索、软归档与恢复。旧日志只幂等导入，不修改原文件。
5. 观察预案分价格与时间条件，只产生本机记录；失效或到期锁定，不能价格反弹就自动复活，保存新预案才重置。服务运行期间不依赖浏览器开着，但电脑休眠/进程退出时不监控。
6. 最近变化区保留研究状态变化、人工依据、自选管理和预案事件。没有偷偷开通消息推送或下单。
7. 研究列表支持路径、状态、代码/名称/题材查询及分页。列表简写缺失项，完整内容在详情，防止把大量规则铺成长段重复文本。
8. 窄窗口补充原生区块跳转入口；保留桌面侧栏，记住盘口分组/排序和研究路径。
9. 焦点区取消固定只显示14条的截断，标题解释组间、环节间与组内排序及标签涨停合计可能重叠。旧补涨算法保留为C级结构对照，删除未经验证的确定性退出/高度比例说法。

## 六、实验与回测验证协议

当前已经实现的是：版本化规则注册、来源哈希、三态核验、原始输入快照、冻结输入复算、前瞻队列结果工具。尚未完成的是经样本外验证的可成交策略回测，不把前者冒称后者。

快照包含当时特征、人工证据、核验时间、证券范围、股池/规则哈希、逐只报价时刻与引擎源码哈希。相同输入不反复保存；发生变化时每分钟保留首份快照。复算采用冻结规则和输入，源码不一致会拒绝复算，要求切回对应代码版本。

```sh
.venv/bin/python scripts/strategy_lab.py list
.venv/bin/python scripts/strategy_lab.py replay --snapshot <ID> --out /tmp/replay.json
.venv/bin/python scripts/strategy_lab.py outcomes --snapshot <ID> --strategy wind_a --horizon 5 --out /tmp/outcomes.json
```

结果工具仅计算条件齐备标的从下一交易日开盘到第1/5/10/20交易日收盘的复权表现，以及MAE/MFE、同一冻结研究范围等权均值与差值。未来未发生、交易日历不够或有停牌/缺行，标记pending，不填零。它没有模拟成交、资金占用、费用、滑点、涨跌停不可成交，也不代表策略可得收益。试验参数和源码版本登记在独立实验表中。

新策略按以下顺序推进：

1. 写可证伪假设、适用风格、入选/退出/失效与对照基准；冻结版本及参数搜索范围，实验失败也留档。
2. 先做数据及因果检查，再积累当时可得的股票池、题材成员、公告/财务发布时间、盘中报价和人工证据；不能把今天的题材池回填为过去已知。
3. 对纯已完成日线规则进行历史研究；需要盘中带动性、早盘封板等证据的路径，缺历史逐时数据就拒绝完整回测，不能用日线伪造。
4. 训练/验证/最终保留样本分开，滚动样本外验证；持有期重叠时设置隔离区，控制参数搜索与多重比较偏差。120日日线够当前60日位置和技术观察，不足以证明跨周期策略有效。
5. 成交层单独纳入A股T+1、停牌、涨跌停封单不可成交、交易成本与滑点，执行失败不删除样本；与可投资基准、同范围基准及简单规则对照。
6. 按市场环境和时期报告样本数、收益/回撤分布、换手、容量、失败场景和成本敏感性，不只报胜率。样本外和纸面观测通过前保持实验状态。

研究依据：

- [QuantConnect研究指南：前视与幸存者偏差](https://www.quantconnect.com/docs/v2/writing-algorithms/key-concepts/research-guide)：采用时点股票池、可得时刻和冻结输入的原因。
- [QuantConnect滚动优化](https://www.quantconnect.com/docs/v2/writing-algorithms/optimization/walk-forward-optimization)：训练参数与后续样本分离的程序。
- [Tushare复权行情说明](https://tushare.pro/document/2?doc_id=109)：复权因子、行情和技术窗口口径。
- [Bailey等回测过拟合研究材料](https://datagrid.lbl.gov/backtest/Tutorial.pdf)：限制反复挑参、保留失败试验和最终保留样本。
