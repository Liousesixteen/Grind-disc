# 方案：看板「双闸对照」——盘口质量 × 方向强度 平级互验（v1.0 草案）

> 2026-10-25 · 状态：**待拍板，未实施**。证据等级：整体 C 级草案（判读规则多为经验统计），落地后按预判校准账本回填验证。
> 免责：本方案只提供观察读数与组合命名，不构成交易指令；下单以行情软件与 A 级纪律为准。

---

## 〇、一句话

在看板顶部加一排「双闸对照」卡：**闸A＝盘口质量（市场级，答"能不能做/给多少仓"）、闸B＝方向强度（板块级，答"做哪里"）**，两闸平级各出读数，中间一张对照矩阵给组合判定灯；每天 9:25/10:30/13:00/14:30 四时点各快照一次，登记五态（新增/延续/分歧/切换/退潮），与盘后股池的日频榜互为校验。

## 一、设计原则（每条都有出处）

| 原则 | 出处 |
|---|---|
| 两闸平级、相互对照验证 | 熔炼系统 3.5「日内方向登记与盘后 3.4 双口径榜互为校验」；外部调研同源结论：「看总情绪做仓位，看板块情绪做方向，看节点做买卖」 |
| 平级≠同权：**A 闸极端时一票否决** | 熔炼系统环境合力总闸「谁在极端谁一票否决」；退潮期板块再强只许小仓试错（背离5 验证三条件） |
| 四时点快照、节点比阶段名重要 | 233 板块确认四时点（B级）＋熔炼 3.5；调研：量化时代周期被压缩，「节点（状态切换处）比阶段名更重要」 |
| 指标不发明新口径，全部复用 | 情绪条口径已在 pankou.py（肉肉 4.2/5.1/六② 熔入）；梯队口径已在 ladder；禁止另起一套 |
| 只亮灯不指令 | 主框架：读数与判断分离；组合判定全部标 C 级草案 |

## 二、闸A：盘口质量（市场级 → 仓位）

| 指标 | 口径 | 现状 | 经验阈值（C级，只作纵向对比） |
|---|---|---|---|
| 涨停家数 | 不含ST；现有 `_limit_th` 已分 10/20/30cm | ✅ sentiment | <30 冰点｜30–50 偏冷｜50–80 正常｜>80 偏热｜>100 高潮 |
| 炸板率 | 收盘未封住÷触板总数（盘中开板收盘封死不算炸板） | ✅ sentiment | <20% 信心强｜20–30% 正常分歧｜>30% 偏高｜>40–50% 打板九死一生 |
| 炸板回封率 | 炸板后回封 ÷ 炸板 | ✅ 回封/炸板池 可直接算 | >60% 承接强｜<30% 警惕快速退潮 |
| **分级晋级率** | 1进2、2进3 分开算；样本<20 改用绝对家数 | 🆕 需昨日涨停集合（load_kprev 已备） | >70% 发酵｜40–50% 健康｜<30% 冰点；**单日骤降=最灵敏退潮信号** |
| **昨日涨停溢价 / 昨日连板溢价** | 昨日涨停（≥2板）票今日等权涨幅 | 🆕 昨日集合＋今日全市场 pct 可算 | −→正=修复信号；+0.5% 只算弱修复，>3% 有效修复；**首板溢价正+连板溢价负=只做首板不做接力** |
| 跌停/大面数 | 跌停家数；昨日涨停票今日 ≤−8% 计大面 | ✅ 跌停已有；大面 🆕 | 跌停>6 恐慌；大面批量且次日续核=亏钱效应蔓延 |
| 最高连板 + 梯队纵向形状 | 首板/2板/3板+ 各层家数 → 金字塔/菱形/倒三角 | ✅ 最高连板已有；形状 🆕 | 菱形（高标在、中位空）= 塔尖绑架，**禁中位接力** |

## 三、闸B：方向强度（板块级 → 方向）

| 指标 | 口径 | 现状 |
|---|---|---|
| 焦点题材涨停家数/涨停率 | ladder（题材口径，涨停率非家数——项目铁律） | ✅ |
| 链组评级 | 兵数×成色 heat（看板 tb4 组头已有） | ✅ |
| 梯队判定 | 成立/分歧/独木难支/未成梯队；龙头/龙头板/龙头炸板/中军 | ✅ ladder |
| 题材相对超额 | 题材均涨 − 全市场中位（强弱用相对超额） | ✅ 窗口A |
| **主线集中度** | 焦点题材涨停数 ÷ 全市场涨停数 | 🆕 一行除法 |
| **扩散度** | 最强链内 涨超5% 家数（面状 vs 点状） | 🆕 snapshot 可算 |
| 龙头孤立检查 | 空间板有无同链 2 板跟随（孤立=兑现杀伤大） | 🆕 ladder 内可判 |

## 四、对照矩阵（组合判定灯，全部 C 级）

| | **B 集中（有主线）** | **B 分散（无主线）** |
|---|---|---|
| **A 强** | 🟢 **共振**：233 全绿。做主线核心/半路；仓位按熔炼相位表（发酵相唯一重仓窗口，A0 硬顶不动） | 🟡 **群龙无首**：普涨无方向。只做辨识度最高者＋等收敛，不加仓 |
| **A 弱** | 🟠 **孤军抱团**：新周期信号**候选**，须过三条件（新题材/次日 1进2 有溢价/有中军容量）才许小仓试错（1–2成）；否则=避风港一日游 | 🔴 **退潮**：空仓/≤1成（熔炼：退潮 ≤10%）。逆势板块只登记不追 |

**B 闸内部三条背离细检**（叠加在矩阵灯上）：
1. 高度升＋中位塌（菱形/双峰）→ 高度是个股行为非板块行为，禁中位接力（10-22 实测：4进5=66.7% 但 3进4=0%、2进3=16.7%）；
2. 首板溢价正＋连板溢价负 → 宽度虚胖，只做首板试错不做接力（10-23 实测：+3.38% vs −1.80%）；
3. 龙头强＋跟风死 → 只持股不新开；补涨先于龙头走弱=分歧已现。

## 五、四时点快照与登记（对齐既有机制）

- 快照时点＝SLOTS（9:25/10:30/13:00/14:30），**四时点落档机制已有**，双闸读数随档落盘即可；
- 每时点登记五态：**新增/延续/分歧（待定）/切换/退潮**（熔炼 3.5 原口径）；
- 互验闭环：日内延续＋盘后日频榜同向 → 方向可信度↑；日内切换而日频仍强 → **派发嫌疑**（熔炼 3.5 原文）；
- 次日回填预判校准账本，✗ 三层归因——组合判定灯本身也要接受校准。

## 六、落地改动清单（最小侵入，全部复用现有数据源）

1. `scripts/pankou.py`：sentiment 增补 4 字段（分级晋级率、昨日涨停/连板溢价、大面数）——需要昨日涨停集合，盘中链路 `load_kprev` 已加载，新增参数不破坏盘后调用（不传=跳过，行为不变）；
2. `scripts/intraday_scan.py`：compute_readings 增算 主线集中度、扩散度、梯队形状、双闸组合判定（纯函数，输入 sentiment+ladder，无新网络请求）；
3. `scripts/intraday_board.py`：PAGE 顶部 tb0 前插「双闸对照」卡（两块小仪表＋判定灯＋一行动作倾向），只读 state 新字段，不改配色体系；
4. 口径纪律：不含 ST、连板认定与现有一致、样本<20 用绝对家数、全部新字段带 `_c` 标注（C级草案）；
5. **不改**：A0 硬顶、tb4/tb5 现有口径、四时点落档格式（只增字段）。

## 七、验证方案

1. **历史回看**：用 cache/intraday 已落档的 10-22、10-23 四时点数据跑双闸，预期——10-22 报「A弱+B集中（孤军）」＋菱形告警；10-23 午前报「退潮」、午后报「修复但首板/连板溢价背离」，与实际"深V反包非新周期"一致；
2. **模拟盘一周**：判定灯与预判校准账本并行记录，命中/打脸逐日回填；
3. 升级路径：C 级草案 → 连续 20 交易日校准 → 视命中率决定是否升 B 级并纳入大盘日报 SOP。

## 八、边界与风险

- 阈值全部来自市场实践者经验统计，**必须纵向对比使用**，极端行情（单边指数行情）会失真；
- 组合判定灯是**读数不是信号**，与 A0/层1 的关系是「A 闸极端时否决」单声道，不反向授权加仓；
- 晋级率/溢价两个新指标的昨日集合口径一旦固定就不改（口径中途变更会让序列失去可比性——调研坑①）；
- 双闸对照不解决"买点"，半路/低吸的买点确认仍是 233 3.3 与主框架小右侧的事。
