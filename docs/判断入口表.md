## 三、位置工具七条规则（P1—P7，2026-10-24 全量评估后确立）

> 来源：全量 392 篇提取 55 条「半分位」用法归纳。详见 `knowledge/styles/波哥痕迹学/位置工具全量评估-v3.2.md`。

| # | 规则 | 内容 |
|---|---|---|
| **P1** | **调整浪目标＝前一个推动浪的半分位** | 参照段＝**紧挨着调整浪前面那段推动浪**（不是大级别上涨段！） |
| **P2** | 目标是区间不是点 | 深：半分位—0.618 回撤位中间；浅：半分位—0.382 回撤位中间 |
| **P3** | **深浅交替** | 前浪深（0.382）→ 本浪浅（半分位）；前浪浅 → 本浪深（0.618）；**空间不交替时时间交替** |
| **P4** | **收盘破半分位＝浪型假设作废 → 切换预案** | 「钢门」——这不是支撑破了，是**预案切换触发器** |
| **P5** | **反弹目标也用半分位**（从低点往上量） | 方向由浪型角色决定，**没有固定从哪头量** |
| **P6** | 0.382 ＝ ①深调整的底 ②反弹弱（连 0.382 都不到） | — |
| **P7** | 0.618 ＝ 深调整目标 / 反弹强目标 | — |

> ⚠ **术语陷阱**：波哥口语的「0.618 位」在**反弹场景**下＝标准「0.382 回撤位」。**调整场景下他就是标准量法（从高点往下）。方向由语境决定，不可一概而论。**

## 三之二、旧版口径对照（保留备查）

| 概念 | 算法 | 谁的 | 等级 |
|---|---|---|---|
| **半分位** | `(起 + 止) ÷ 2` | 简单二分，**不是黄金分割** | B |
| **0.382 回撤位** | `止 − 幅度 × 0.382` | 黄金分割（＝起点往上 61.8%） | C |
| **0.618 回撤位** | `止 − 幅度 × 0.618` | 黄金分割（＝起点往上 38.2%） | C |
| **波哥「中点法则」** | `(半分位 + 0.382 回撤位) ÷ 2` | 他口语的"0.618 和半分位中间" | C |

> ⚠ **术语陷阱**：波哥口语的「**0.618 位**」＝标准「**0.382 回撤位**」。按标准 0.618 回撤位算会低 180—380 点。
> 详见 `熔炼系统` 3.10⑤ 的「位置工具三分」。

## 三之三、划分点监控（2026-10-24 新增，波哥浪型划分的可编码核心）

> 方法推断全文见 `docs/波哥浪型划分方法推断.md`。核心结论：**他的「划分点」不是算出来的，是记下来的——每个波段拐点的盘中极值精确价格**（实测 65 个点 61 个精确匹配历史极值，误差 ±0.005）。

**⚠ 按问题选级别，不跑固定命令（2026-10-24 用户要求：「各种级别的都是要灵活使用的」）：**

| 当下的问题 | 用哪个级别 | 怎么用 |
|---|---|---|
| 大级别趋势还在不在 | **周线 / 25% 档** | 结构定性，不盯小波动 |
| 这轮调整跌够没有 | **日线** | 半分位 / 0.382 / 0.618 回撤位 + 等幅投射 |
| 反弹能弹到哪 | **日线反弹位**（`--ref-high`） | 止跌确认后从低点往上画；**60 分钟底背离**确认成色 |
| 日内微结构 / 精确开仓点 | **30 分钟**（`--timeframe 30m --points`） | 微浪主工作台，盯划分点破立 |
| 日线看不清结构 | **切 30 分钟**（「放小看大」） | 看内部 123 结构是否出现，再反推大周期 |
| 盯破立 | **各周期都查，谁近盯谁** | 当前价最近的划分点是有效的开关位 |
| 时间计数 | **从拐点起算** | 用小周期根数量上一级时间（30 分钟根数÷8≈交易日） |

> 结论常需**多级别交叉**：「空间到了 / 级别够了 / 信号未到」三个读数来自三个不同工具——单点不定论。多周期分工与证据见 `docs/波哥浪型划分方法推断.md` 三之二；分钟模式级别分层暂无意义（全标微级），微浪划分点才是重点。

输出四列关键信息：**精确价格 / 日期 / 级别标签 / 距现价距离**，并自动标注每点是「上方阻力（突破=结构成立）」还是「下方防线（跌破=结构作废/升级）」。

**用法（他的四件套）**：
1. **盯破立**：价格距划分点 ±0.01 即二值判定，无中间状态；
2. **从拐点起算时间**：调整天数以划分点日期为 Day 0（「3794 点以来的第 26 天」）；
3. **时间 2 倍律**：新调整时间 > 上一同向段最长调整 × 2 → 级别升级；
4. **特征匹配**：浪型身份有行为特征（主升=快而猛），速度不符即改判。

**已验证的复现**：表能自动抓出 3750.77（他 10-19 提的小右侧确认线）、3674.82（本波生死线）、3864.12（他 10 月帖的划分点）、3574.27（他认定的底）。

**局限（必须记住）**：微浪端点的「身份」（哪个高点算微 3 浪顶）是人工判断——3743.80（他用的 10-19 高点）在本表 1.1% 阈值下走了另一条分段路径（记为 3692.29 低点后的反弹），算法与人对微浪端点的认定可能不同。**表给原料，身份链靠人。**

## 四、判读天花板（防止日频结论越级）

| 大级别状态（25% 或波哥 long 级） | 日频看多最高只能给到 |
|---|---|
| 上涨未破（回撤 &lt;25%） | 「启动」 |
| 已确认转折（回撤 &gt;25%） | **最高「修复/反弹」** |
| 已确认转折且回撤 &gt;50% | 需「右侧确认 ＋ 缩量止跌」双条件 |

**当前（2026-10-23）**：上证 long 级仍是上涨段（自 4242.57 仅跌 13.01% &lt; 15%）→ 属第一档；但 mid 级已确认下跌 109 日 → **判级别要分档说，不能一句"大盘怎样"**。

## 五、冲突处理（三条，不要自行仲裁）

1. **波哥口径 vs 多阈值口径**：一个说"级别+点位"，一个说"谁在跌"——**两个问题，不是两个答案**。
2. **技术 vs 消息**：消息只决定"看哪里"，不决定"买不买"（仍过层0—层4）。
3. **大级别 vs 日频**：日频结论**不得越过天花板**；越了就是错。
